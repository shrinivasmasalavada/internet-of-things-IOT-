## What is IoT?

IoT means connecting physical devices to the internet so they can:

* Collect data
* Send data
* Receive commands
* Work automatically

Example:

* Smart lights
* Smart agriculture
* Smart CCTV
* Smart factories
* Health monitoring devices

## Flow

### Sensor → Microcontroller → Internet → Cloud → Mobile App

Example:

1. Temperature sensor reads data
2. ESP32 processes data
3. Wi-Fi sends data to cloud
4. Mobile app shows live status
